# Phase 14 Balance Report

Stage 1 base completion rewards are 400 XP, 500 credits, and the fixed-design Reactor Matrix. The optional objective, chain, boss challenge, and secret branch use the existing reward multiplier. A fresh profile seeded 50 XP below level 2 can level from the mission, demonstrating the progression loop. Replay rewards use the established 70% replay rate and every run receives a unique idempotent transaction ID.

The roster contains eight functional slots: formation fighter, aimed shooter, predictive shooter, flanker, turret/sentinel, shielded elite, hazard carrier, and miniboss support. Final numeric tuning remains a playtest item.
